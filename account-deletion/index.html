앱에서 삭제하기 (카카오 로그인 계정)

  1. 앱 아래쪽의 설정 탭을 엽니다.
  2. 맨 위의 프로필을 누르면 프로필 수정 화면이 열립니다.
  3. 아래쪽의 회원 탈퇴를 누릅니다.
  4. 탈퇴하기를 누르고, 확인 창에서 탈퇴를 누릅니다.

탈퇴하지 못하면(카카오 연결 해제 실패 등) 계정은 그대로 남고, 잠시 후 다시 시도하라는 안내가 나옵니다.

앱 없이 삭제 요청하기

앱을 지웠거나 로그인 없이 쓰던 계정은 고객 문의로 삭제를 요청해 주세요. 본인 확인 뒤 처리합니다. [확인 필요: 처리 절차·기한]

삭제되는 것

  • 계정과 카카오 연결
  • 닉네임, 약관 동의 기록
  • 집중 기록과 잔디, 졸음 기록, 측정값
  • 버디, 경험치, 배지, 순위 기록
  • 콕콕이 연결 정보와 기기 설정
  • 친구 관계, 주고받은 응원 (보낸 응원은 받은 사람에게서도 사라집니다)

삭제는 되돌릴 수 없습니다.

계정은 두고 일부 기록만 지우기

앱 안의 기능은 준비 중입니다. 지금은 고객 문의로 지울 기록을 알려 주시면 본인 확인 뒤 처리합니다. [확인 필요: 처리 절차·기한]
